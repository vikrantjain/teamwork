# Intent

This is the human's statement of what the plugin is built for. It is not
instructions for a team using the plugin, and nothing in the plugin loads it.
Claude does not edit it. The decisions in `CLAUDE.md` are derived from it and
are tested against it.

The plugin is lean in size, highly abstract, simple and flexible. Lean is
measured on what a member reloads every turn, not on what the lead reads once
when forming a team.

It supports multiple separate agent sessions that interact with each other
through Claude's messaging.

The work assigned can be anything. It is not limited to software development.

On a fresh project, the rules of work are decided when the team forms. On work
already under way, the rules are adopted from what is there.

The lead can hold one role or several, as long as no other lane waits on it: an
integration tester, a full system deployer, a documenter, or an overall reviewer
of the work the team members did. It manages by partitioning the work up front
rather than by handing out items one at a time.

When the plugin is installed on the lead, it can read the plan if one is
available. It can suggest a team structure. It can hold a question-and-answer
session with the human about the expected team structure. It can do more than
one of these.

The ultimate goal is complete collaboration to achieve the final goal: minimum
conflicts, minimum duplication of effort, parallel work, and context that is
optimized and isolated.
